# 장비 Codex

UI는 AI 비서와 같은 전체 영역 채팅 형태다. 상단에 장비 Codex·현재 대화·새 대화·설정 및 사용량을 두고, 장비와 적용 작업 폴더를 바로 아래에 표시한다. 대화 본문과 하단 입력창은 최대 1120px로 가운데 정렬하며 사용자 메시지는 오른쪽 말풍선, Codex 답변은 15px 본문으로 표시한다. 빈 대화의 중앙 안내에 장비 상태·로그·배포·Git 제안 버튼을 둔다.

장비 선택·폴더·CLI/GitHub 설정·대화 기록·계정은 접을 수 있는 왼쪽 사이드바에 모은다. 처음 장비를 선택하면 연결 설정을 열고 연결 완료 후 닫는다. 상단 ☰ 또는 장비 이름으로 다시 열며 대화 기록 선택 후 본문으로 돌아간다. 700px 이하에서는 배경 닫기·Escape·키보드 포커스 순환을 지원하는 서랍 형태다. 사이드바 토글은 대화·입력 DOM을 다시 만들지 않아 작성 중 내용과 스크롤을 유지한다. 실행 중에도 열고 닫을 수 있지만 실행 대상과 권한 변경은 계속 제한한다. 인증 링크·코드와 취소는 본문에서 확인한다.

화면 전체 폭과 남은 높이를 대화에 사용한다. 장비·작업 폴더 설정은 연결 후 접히며 상단 요약을 눌러 다시 연다. 장비를 바꾸면 설정을 펼친다. 첫 메시지 이후 예시 질문을 숨기고 입력창은 하단에 유지하며 대화 영역 내부에서 스크롤한다. IDE와 같은 사용자 메시지 확인·중복 이벤트 갱신 로직을 사용한다. [채팅 동작](codex.md).

인프라 장비 카드의 **Codex**, 또는 앱 라이브러리·검색의 **장비 Codex**에서 연다. 등록한 SSH 장비와 절대 경로의 작업 폴더를 선택하고 **연결 · CLI 준비**를 누른다. Linux x86_64/aarch64 장비에 해당 SSH 사용자 권한으로 CLI와 같은 버전의 code-mode-host를 설치한다. 공식 GitHub release의 SHA256을 검증하며 최신 조회 실패 시 검증된 기본 버전 또는 정상 설치 버전을 사용한다. 설치에 필요한 권한이 없으면 오류를 표시한다.

기기 코드 로그인은 인증 링크와 복사할 일회용 코드를 표시한다. 로그인 후 선택한 장비의 계정 이메일을 확인할 수 있다. 인증 정보는 장비에 남으며 응답은 공개 계정 정보만 제공한다. GitHub 로그인은 해당 SSH 사용자의 `gh` 인증과 Git credential helper를 설정한다.

| 기능 | 실행 위치 | Codex 상태 저장소 |
| --- | --- | --- |
| AI 비서 | 대시보드 서버 | 서버 Codex 설정 및 대시보드 MCP |
| 코드 에디터 Codex | 선택한 SSH 프로젝트 | 기존 SSH 사용자 Codex 설정 |
| 장비 Codex | 선택한 SSH 장비의 작업 폴더 | `~/.local/share/personal-workspace/device-codex/<장비 ID SHA256>` |

전용 `CODEX_HOME`으로 계정, 설정, 대화 기록을 분리한다. 설치 바이너리는 같은 SSH 계정의 `~/.local/bin`을 공유한다. 대시보드 MCP는 등록하지 않고 비활성화한다. 상속된 API 키와 대시보드 MCP 자격 증명은 장비 Codex 자식 프로세스에서 제외한다. [공식 환경 변수 계약](https://learn.chatgpt.com/docs/config-file/environment-variables)을 따른다.

상태·로그·배포·Git 안내 버튼은 요청문을 입력창에 채우며 전송 시 실행한다. 로그 분석은 장비의 실제 시각, 프로세스·포트·컨테이너와 보관 로그를 확인하도록 지시한다. 기간·시간대·누락·권한 부족을 구분하고 HTTP 5xx와 예외 문맥을 조사한다. 실행 도구 출력과 최종 결과를 대화에서 확인할 수 있다.

상단 **설정 · 사용량**에서 실행 범위와 명령 승인 정책을 선택한다. 기본값은 `read-only` + `on-request`다. 파일 변경은 `workspace-write`, 작업 폴더 밖 파일·배포·네트워크까지 SSH 사용자 권한으로 실행하려면 `danger-full-access`를 선택한다. **승인 요청 안 함**(`never`)은 명령마다 묻는 승인을 끄며 제한된 작업은 질문 대신 실패한다. 전체 접근과 함께 선택하면 샌드박스 제한 없이 명령 승인을 묻지 않는다. 작업 내용에 관한 모델 질문은 계속 표시한다. SSH 계정에 OS 권한을 자동 부여하지 않는다. 배포·파일 수정·Git 작업은 모델의 실제 명령 실행과 검증 결과를 통해 완료 여부를 확인한다. 중지는 이후 실행을 멈추며 이미 적용한 변경을 되돌리지 않는다.

대화·승인·모델·추론 강도·첨부·세션 목록·분기·복원은 공통 Codex 패널을 사용한다. 작업 중에는 장비/폴더와 실행 설정 변경을 막으며 설정 화면 조회·닫기는 가능하다. 장비나 적용 폴더 변경 시 계정과 대화 표시를 초기화한다. `sessionStorage`에 장비·폴더별 대화 ID와 모델·추론 강도·실행 범위·승인 정책을 저장하고 IDE와 분리한다. 처음 여는 대상은 기본값으로 시작한다. 계정·사용량·인증정보는 저장하지 않는다. 작업은 로그인 세션과 장비 ID로 묶이며 다른 장비나 IDE/AI 비서 경로에서 조회·제어할 수 없다. 서버 공통 동시 실행 4개, 보관 32개, 실행 제한 15분을 공유한다.

설정 화면에 계정별 한도 잔여 비율·기간·초기화 시각과 대화의 누적/입력/캐시 입력/출력 토큰·컨텍스트 사용량을 표시한다. 계정 한도는 연결·새로고침·완료된 대화 후 조회하고 수동 갱신도 가능하다. 미제공/조회 실패는 표시하되 채팅을 막지 않는다. 사용 한도를 정확한 잔여 토큰으로 환산하지 않으며 토큰 이벤트가 없는 복원 대화는 대기로 표시한다.

대시보드 자체 `local` 항목은 지원하지 않는다. 호스트를 관리하려면 해당 호스트를 SSH 장비로 등록한다. [Codex 검증](codex-validation.md)에 로컬 SSH 검증 절차를 기록한다.
