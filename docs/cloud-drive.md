# 개인 클라우드 드라이브

앱 목록 → **클라우드 드라이브**에서 사용한다. 구글 드라이브처럼 대시보드 서버에 파일을 저장하는 단일 계정 전용 공간이다. Google 계정/Drive API 연동이나 외부 공개 공유 기능은 아니다. 모든 파일 작업과 ZIP 생성은 서버에서 실행한다.

## 사용 기능

- 내 드라이브 탐색, 폴더 경로 이동, 하위 폴더 포함 이름 검색, 이름/크기/최근 수정 정렬, 목록/격자, 100개씩 페이지 이동.
- 새 파일·폴더, 파일 및 폴더 업로드, 파일 드래그앤드롭, 다중 업로드 진행률과 취소. 브라우저의 폴더 업로드 기능이 필요하며 비어 있는 폴더는 새 폴더 버튼으로 생성한다. 폴더 드래그는 폴더 업로드 버튼으로 안내한다.
- 다중 선택 다운로드, 파일 직접 다운로드, 폴더/다중 선택 ZIP 다운로드. ZIP은 선택한 최상위 이름과 하위 구조를 유지한다.
- 이름 변경, 위치 선택 창을 통한 파일·폴더 복사/이동, 복사 대기/잘라내기/붙여넣기. 단일 항목 복사는 대상 이름을 지정할 수 있으며 기본 사본 이름을 제안한다. 이름 충돌을 자동으로 덮어쓰지 않는다.
- 삭제는 휴지통으로 이동한다. 휴지통 목록, 원래 위치 복원, 선택 영구 삭제, 휴지통 비우기. 원래 위치 이름이 이미 있으면 복원을 거부하고 기존 파일을 보존한다.
- 파일 속성(가상 경로, 종류, 파일 바이트 크기, 수정 시각), 20 MiB 이하 PNG/JPEG/GIF/WebP 미리보기, 1 MiB 이하 UTF-8 텍스트 미리보기·편집. 다른 형식/큰 파일은 다운로드로 확인한다. 텍스트 저장은 읽은 시점의 SHA-256 revision을 확인해 다른 변경의 덮어쓰기를 막는다.
- Ctrl/Cmd+A는 현재 페이지 선택, C/X/V는 내부 파일 복사/잘라내기/붙여넣기, Delete는 삭제(휴지통에서는 영구 삭제 확인), F2는 이름 변경. 입력 필드와 대화상자에서는 가로채지 않는다.

## 파일 보존과 제한

`CLOUD_ROOT`(Compose 기본 `/app/data/cloud`) 아래 `files/`, `trash/`, `staging/`을 사용하며 기본 dashboard-data 볼륨에 유지된다. 자체 서버 실행 기본은 `./data/cloud`다. 다른 경로로 설정하면 해당 경로를 영구 볼륨으로 마운트해야 한다. 백업은 세 폴더를 포함한 데이터 볼륨을 대상으로 하되, 업로드/복사 중은 피한다. 기존 SSH/SFTP 파일 탐색과 별도 저장 공간이다.

업로드는 파일별 요청이며 `UPLOAD_MAX_SIZE`(기본 1GB)를 적용한다. 같은 이름 덮어쓰기는 기본 꺼져 있다. 켜면 해당 파일을 교체하며 별도 버전 이력은 만들지 않는다. 실패한 파일 업로드는 기존 파일을 보존하고 임시 파일을 정리한다. 취소는 현재 요청과 대기 중 파일을 중지하며 이미 업로드된 파일을 되돌리지 않는다. 요청 취소 직전 서버 저장이 끝난 파일도 남을 수 있다.

한 번의 목록/검색 스캔·재귀 파일 작업은 최대 10,000개 항목이다. 검색은 현재 폴더부터 내려가며 검색량 제한에 도달하면 잘린 결과 안내를 표시한다. ZIP 선택은 1~100개, 전체 ZIP 항목은 최대 10,000개이고 서버 임시 디스크 공간을 사용한다. 부모와 자식을 함께 선택하면 ZIP에 중복 포함하지 않는다. 같은 이름의 서로 다른 최상위 항목은 각각 다운로드한다. 대용량 ZIP 생성은 다운로드 시작까지 시간이 걸릴 수 있다. 서버 저장 공간 표시는 파일시스템 전체 여유/전체 용량이며 드라이브 전용 할당량은 아니다.

복사/이동/삭제/복원 다중 선택은 파일별로 순차 수행한다. 실패한 항목과 완료 수를 화면에 표시하며 다른 성공 작업을 되돌리지 않는다. 정상 삭제는 영구 삭제가 아니다. 휴지통은 자동 만료하지 않고 공간을 차지하므로 필요할 때 비운다. 임시 staging은 정상 완료/실패 및 다운로드 스트림 종료 시 정리하며 비정상 프로세스 종료로 남은 임시 파일은 정지 상태에서 별도 정리할 수 있다.

모든 API는 OWNER 세션을 요구하고 변경 요청에 CSRF를 적용한다. 경로는 드라이브 내부의 `/...` 가상 경로이며 `..`, 역슬래시, 제어 문자, 루트 변경, 심볼릭 링크와 특수 파일을 거부한다. 삭제와 임시 정리는 검증된 관리 폴더 안에서만 재귀 수행하고 링크를 따라가지 않는다. 응답에 서버 실제 파일 경로를 반환하지 않는다. 다운로드는 attachment이며 미리보기의 파일 텍스트는 HTML로 실행하지 않는다. 원격 계정 권한 변경, 파일 실행, 심볼릭 링크 생성, 외부 공유는 제공하지 않는다.

검증: Maven `verify`(Linux Docker에서 심볼릭 링크 테스트 포함), `node tools/launcher/cloud-test.cjs`, 기존 launcher/theme 검사. 실제 브라우저 레이아웃과 터치 동작은 별도 검증 대상이다.

## NAS 연결

클라우드 드라이브의 **NAS 연결**에서 동일 저장소를 WebDAV로 연결한다. 네트워크 파일 잠금은 웹 변경에도 적용한다. 연결 방법과 지원 범위는 [NAS 안내](nas.md)를 따른다.

파일·폴더 이름과 아이콘은 좌측 정렬한다. 파일 클릭은 팝업 대신 드라이브 영역 전체를 사용하는 전용 에디터 화면으로 이동한다. 텍스트 저장, 이미지 열람, 다운로드와 드라이브 복귀를 제공한다. 미저장 상태에서 복귀하거나 페이지를 닫으면 확인하며 다른 앱으로 이동했다 돌아오면 편집 버퍼를 유지한다.
