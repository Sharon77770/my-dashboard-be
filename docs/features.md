등록하지 않은 장비, 설치하지 않은 원격 프로토콜/CLI의 상태나 결과를 만들어 내지 않는다. 오류는 재시도 또는 설정 변경으로 복구한다.
서버 Chromium과 원격 브라우저는 실제 데스크톱을 공유한다. 실행 탭 복원은 기존 프로세스 복구를 의미하지 않는다.

### 명령어로 SSH 연결
터미널 화면에서 등록 없이 서버 터미널을 열고 `ssh 사용자@호스트`를 실행한다. 비밀번호와 최초 호스트 확인은 OpenSSH 터미널 프롬프트를 사용한다. OpenSSH client, scp, sftp를 Docker 이미지에 포함하고 셸 홈 및 known_hosts를 데이터 볼륨에 보존한다. 파일 UI/계측용 저장 장비와 독립적으로 사용한다.

### SSH 명령 기반 장비 추가
장비 추가의 기본 UI는 SSH 명령어·비밀번호·선택 이름이다. 지문과 SFTP 경로는 서버가 자동으로 확인하여 저장한다. 성공한 장비는 기존 SSH/파일/계측 기능에서 사용한다. RDP/VNC 및 세부 경로는 직접 설정으로 관리한다. 최초 키는 자동 신뢰하며 저장된 키 변경은 차단한다. 지원 인증은 비밀번호이며 -p 이외의 옵션은 지원하지 않는다.

장비 직접 설정/수정에서도 SSH 지문 수동 입력란을 제거했다. 기존 키 유지 또는 새 SSH 대상 자동 확인은 CatalogService가 수행한다.

## 캘린더·시간표
- 캘린더: 월간 42일 격자, 월 이동/직접 선택/오늘, 선택 날짜 일정 목록, CRUD, 종일·여러 날 일정, 장소·메모·색상. 격자에 3개까지 표시하고 나머지는 날짜 목록으로 확인.
- 시간표: 학기별 CRUD, 월~일 7열 시간축, 빈 칸 클릭 추가, 과목 CRUD, 여러 요일/시간 등록, 교수·강의실·학점·메모·색상. 기본 08~20시, 수업에 맞춰 00~24시까지 표시 범위 확장. 학점 서버 합계와 충돌 검증.
- 참고: [에브리타임 공식 앱](https://play.google.com/store/apps/details?hl=ko&id=com.everytime.v2), [Google Calendar 일정 관리](https://support.google.com/calendar/answer/37113?hl=ko). 월간 달력+날짜 목록과 대학 시간표의 요일/시간축·과목별 색상 패턴을 자체 UI로 구현. 외부 계정이나 학교 강의 데이터에 연결하지 않는다.
- 모바일: 캘린더 상세 목록을 격자 아래에 배치, 시간표 최소 너비를 유지한 가로 스크롤. 기존 라이트/다크 테마 적용.

## Tailscale 지원
Docker에 공식 Tailscale을 기본 포함한다. 최초 로그인 후 Tailscale IP/MagicDNS로 SSH 장비를 등록하고 파일·계측·RDP/VNC·서버 브라우저에서 같은 네트워크를 사용할 수 있다. 인증 전에는 로컬 대시보드를 계속 사용할 수 있다. Tailscale 인증은 별도 영속 볼륨으로 유지한다. 기존 SSH 계정/서버 접근 정책은 유지하며 Tailscale SSH 전용 계정 정책을 자동 생성하지 않는다.

## 카카오톡과 외부 인증
Launcher/Dock/앱 목록/검색에서 카카오톡을 열면 서버 Wine 화면을 기존 원격 터널로 전달한다. 설치와 실행은 자동화하고 CLI 재실행을 지원한다. 창 입력, 한글 입력기, 탭 저장/복원, 최근 이력을 지원한다. 카카오톡 프로필은 별도 영속 볼륨에 저장한다. 외부 인증은 CLI/키 주입을 우선하며 카카오톡처럼 공식 CLI 인증이 확인되지 않은 경우 서버 앱 화면에서 입력한다. [외부 인증 검증 기준](authentication.md)에 따라 실제 계정 대신 임의 입력의 거부까지만 검증한다.

## SSH 코드 에디터

파일 트리·편집 탭·Git 관리·Codex 실행 및 GitHub/Codex 기기 코드 로그인을 제공한다. 서버 자체 및 SSH 장비에서 CLI를 실행한다. 자동 설치와 사용 범위는 [사용 안내](studio.md)를 참고한다.

## Launcher 구조

[Launcher 계약](launcher.md)에 따라 앱/폴더/위젯/페이지/Dock/App Drawer를 제공한다. 이전 홈의 최근 작업과 클립보드는 앱으로 이동했으며 장비 상태는 위젯과 장비 앱에서 제공한다. Home 배치는 계정별 브라우저 저장이고 업무 데이터의 SQLite 저장은 그대로다.

장비 등록·수정 및 SSH 명령어 연결에서 기본 네트워크/Tailscale을 선택할 수 있다. 선택은 장비에 저장되고 SSH·SFTP·터미널·IDE·계측·Docker/GPU·RDP/VNC·원격 브라우저 서버 접속에 공통 적용된다. [사용법](tailscale.md).

- 장비 로그: [Docker 연속 로그와 tmux 실시간 화면](device-logs.md). 기본 서버 및 등록 SSH/Tailscale 장비의 읽기 전용 출력을 제공한다.

- Tailscale 웹 설정: 공식 로그인 링크 발급, 연결 상태/호스트/IP 확인, 로그아웃. 시스템 메뉴 및 앱 목록에서 접근한다. 상세: [Tailscale](tailscale.md).

- [클라우드 드라이브](cloud-drive.md): 영구 개인 저장소, 파일·폴더 업로드/다운로드/ZIP, 복사·이동·이름 변경, 휴지통·복원·영구 삭제, 검색·다중 선택·텍스트 편집.

## 드라이브 NAS

기존 클라우드 드라이브를 WebDAV로 제공하며 기기별 연결 안내, 환경변수 공개 주소, 동일 계정 인증, 파일 잠금과 휴지통을 지원한다. [설정 및 호환 범위](nas.md).

## 원격 데스크톱 자동 구성

장비 카드의 원격 자동 연결에서 기존 VNC/RDP 검증 또는 SSH 대상 Linux 가상 화면 설치와 연결을 진행한다. 포트 충돌·권한·지원 OS·기존 설치를 구분해 처리한다. [지원 범위](remote-desktop.md).
